# Python 數學運算入門

適合程度：國中～高中

## 1. 基本運算子

Python 可以直接當計算機使用，以下是最常用的數學運算子：

| 運算子 | 說明 | 範例 | 結果 |
|--------|------|------|------|
| `+`  | 加法 | `3 + 5` | `8` |
| `-`  | 減法 | `10 - 4` | `6` |
| `*`  | 乘法 | `6 * 7` | `42` |
| `/`  | 除法（結果是浮點數） | `7 / 2` | `3.5` |
| `//` | 整數除法（無條件捨去小數） | `7 // 2` | `3` |
| `%`  | 取餘數（模運算） | `7 % 2` | `1` |
| `**` | 次方（指數） | `2 ** 3` | `8` |

```python
print(3 + 5)    # 8
print(7 / 2)    # 3.5
print(7 // 2)   # 3
print(7 % 2)    # 1
print(2 ** 10)  # 1024
```

## 2. 運算的優先順序

跟數學一樣，Python 也遵守「先乘除、後加減」的規則，也可以用括號 `()` 改變順序：

```python
print(2 + 3 * 4)      # 14，先算 3*4=12，再加 2
print((2 + 3) * 4)    # 20，先算括號內 2+3=5，再乘 4
```

優先順序（由高到低）：
1. `()` 括號
2. `**` 次方
3. `*`、`/`、`//`、`%`
4. `+`、`-`

## 3. 常用內建數學函式

```python
print(abs(-5))       # 絕對值，結果 5
print(round(3.14159, 2))  # 四捨五入到小數第2位，結果 3.14
print(max(3, 7, 2))  # 最大值，結果 7
print(min(3, 7, 2))  # 最小值，結果 2
print(pow(2, 5))     # 等同 2 ** 5，結果 32
```

## 4. math 模組（進階數學運算）

想要開根號、三角函數、圓周率等，需要匯入 `math` 模組：

```python
import math

print(math.sqrt(16))    # 開根號，結果 4.0
print(math.pi)           # 圓周率 3.14159...
print(math.floor(3.9))   # 無條件捨去，結果 3
print(math.ceil(3.1))    # 無條件進位，結果 4
print(math.factorial(5)) # 階乘 5! = 120
```

## 5. 變數與數學運算結合

```python
# 計算圓面積
import math

r = 5  # 半徑
area = math.pi * r ** 2
print(f"圓面積為 {area:.2f}")  # 圓面積為 78.54
```

## 7. 小提醒

- `/` 一定回傳浮點數（小數），即使整除也一樣，例如 `10 / 2` 結果是 `5.0`。
- `//` 對負數會「無條件捨去」，例如 `-7 // 2` 結果是 `-4`，不是 `-3`。
- 浮點數運算可能有誤差，例如 `0.1 + 0.2` 不會剛好等於 `0.3`，這是電腦儲存小數的方式造成的。
